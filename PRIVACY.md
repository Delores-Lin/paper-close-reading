# Privacy Policy

Effective date: July 11, 2026

Paper Close Reading is a skills plugin with instructions, reference files, and
small local helper scripts. The helpers do not operate a separate server,
create user accounts, set or export browser cookies, or independently collect,
sell, or share personal information.

When a user asks an AI agent to read a paper, the host product may process uploaded files, prompts, generated responses, and tool activity under the host provider's terms and privacy policy. If the host retrieves external paper metadata, Scholar search results, or a user-requested public PDF, those services may receive ordinary network request information according to their own policies. The lookup helper writes no local paper record unless the caller explicitly supplies an opt-in cache path; an opt-in cache contains sanitized paper candidates and provenance, not account/avatar fields or browser credentials. Requested PDF files are written only to the caller-selected output path after validation.

Users should not provide confidential, restricted, or personally identifiable material unless they are authorized to process it in the selected host environment. The plugin instructs the host to minimize quotations and avoid fabricating source evidence, but users remain responsible for verifying outputs before academic, professional, or publication use.

Questions or privacy concerns can be submitted through the project's support channel:

https://github.com/Delores-Lin/paper-close-reading/issues
