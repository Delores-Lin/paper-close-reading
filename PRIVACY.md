# Privacy Policy

Effective date: July 11, 2026

Paper Close Reading is a skills-only plugin. The plugin package contains instructions and static reference files. It does not operate a separate server, create user accounts, set cookies, or independently collect, store, sell, or share personal information.

When a user asks Codex or ChatGPT to read a paper, the host product may process uploaded files, prompts, generated responses, and tool activity under the host provider's terms and privacy policy. If the host retrieves external paper metadata or public sources, those services may receive ordinary network request information according to their own policies.

Users should not provide confidential, restricted, or personally identifiable material unless they are authorized to process it in the selected host environment. The plugin instructs the host to minimize quotations and avoid fabricating source evidence, but users remain responsible for verifying outputs before academic, professional, or publication use.

Questions or privacy concerns can be submitted through the project's support channel:

https://github.com/Delores-Lin/paper-close-reading/issues
