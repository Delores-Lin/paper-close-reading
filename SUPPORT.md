# Support

Use GitHub Issues for bug reports, feature requests, policy concerns, and reproducible examples:

https://github.com/Delores-Lin/paper-close-reading/issues

When reporting a problem, include:

- the host product and version;
- the user prompt, with confidential content removed;
- the source type, such as PDF, arXiv, DOI, HTML, or pasted text;
- the expected behavior and actual behavior;
- whether the issue involves extraction, source locations, figures, tables, metadata, or output formatting.

Do not post private papers, credentials, personal data, or copyrighted full text in a public issue.
