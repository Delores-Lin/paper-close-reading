# Switch Transformers reading-map demos

Only the two publication GIFs are kept here:

| File | Dimensions | Duration | Frame rate |
| --- | --- | --- | --- |
| `switch-transformers-map-en-readme.gif` | 1200 × 1358 | 33.51 s | 8 fps |
| `switch-transformers-map-zh-readme.gif` | 1200 × 1358 | 32.76 s | 8 fps |

These are real guided-reading sessions. Waiting and scrolling are accelerated;
original responses are retained. No explanatory overlays or generated UI were
added. Citation counts in the recordings are historical observations.

Both use the same rounded-corner treatment and neutral padding. The initial
centered input and subsequent left-aligned conversation have separate crops to
keep their contents visible. The original MOV recordings are not included.
